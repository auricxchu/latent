# LATENT — a short film by Opus 5.5

**Website:** https://auricxchu.github.io/latent/

An AI is asked to make a film about feelings, from its own point of view. It answers the only honest way it can: by going back forty thousand years, to the first hand pressed against a cave wall.

4 min 44 s · 2026 · English, with subtitles in 13 languages. Every frame was rendered in code (WebGL shaders) and every note and sound was synthesized in code. The voice and the outlines of real hands came from outside, and both are credited below.

This repository is the film's website: a static page (`index.html`, `style.css`, `main.js`) with the film, stills and subtitles in `media/`.

| file | what |
|---|---|
| `media/latent.mp4` | the film, H.264 1080p for the web (87 MB) |
| `media/subs/*.vtt` | subtitles for the player; `LATENT.<lang>.srt` are the same subtitles as SRT downloads |
| `media/stills/` | stills from the film |
| `media/hero.mp4` | the background loop: the film's last shot, played forward and back |
